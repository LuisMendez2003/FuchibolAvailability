# ¿Cuándo jugamos? — Disponibilidad de la pichanga ⚽

Sitio súper simple para que tu grupo marque en qué fechas está libre para jugar,
y ver de un vistazo cuál es la mejor fecha para separar la cancha.

- **Frontend**: HTML + CSS + JavaScript puro (sin frameworks, sin build).
- **Base de datos compartida**: Supabase (Postgres gratis) — así todos ven las
  mismas respuestas desde cualquier celular o compu.
- **Hosting gratis**: Netlify (el más simple, arrastrar y soltar).

No necesitas saber programar para desplegarlo, solo seguir los pasos.

---

## Paso 1 — Crear la base de datos en Supabase (gratis)

1. Ve a https://supabase.com y crea una cuenta gratis.
2. Crea un **New Project** (elige cualquier nombre y una contraseña de base de
   datos, guárdala por si acaso).
3. Cuando el proyecto esté listo, ve a **SQL Editor** (menú izquierdo) →
   **New query**, pega esto y dale **Run**:

   ```sql
   create table events (
     id bigint generated by default as identity primary key,
     name text not null,
     created_at timestamp with time zone default now()
   );

   create table availability (
     id bigint generated by default as identity primary key,
     event_id bigint not null references events(id) on delete cascade,
     person_name text not null,
     date date not null,
     status text not null check (status in ('available', 'unavailable')),
     created_at timestamp with time zone default now()
   );

   alter table events enable row level security;
   alter table availability enable row level security;

   create policy "acceso publico eventos" on events
     for all using (true) with check (true);

   create policy "acceso publico disponibilidad" on availability
     for all using (true) with check (true);
   ```

   Esto crea la tabla y permite que cualquiera con el link lea y escriba
   (está bien para un grupo cerrado de amigos; nadie fuera del link sabrá
   que existe).

4. Ve a **Project Settings** (ícono de engranaje) → **API**. Copia:
   - **Project URL**
   - **anon public** key (la llave larga)

---

## Paso 2 — Configurar el sitio

1. Abre el archivo `config.js` que te compartí.
2. Reemplaza las dos líneas con lo que copiaste en el paso anterior:

   ```js
   const SUPABASE_URL = "https://tuproyecto.supabase.co";
   const SUPABASE_ANON_KEY = "eyJhbGciOi....(tu llave larga)";
   ```

3. Guarda el archivo.

---

## Paso 3 — Subirlo gratis a Netlify

1. Ve a https://app.netlify.com/drop
2. Arrastra la carpeta completa `futbol-disponibilidad` (con `index.html`,
   `style.css`, `app.js` y tu `config.js` ya editado) a esa página.
3. En segundos Netlify te da un link tipo
   `https://algún-nombre-random.netlify.app` — ¡ese es tu sitio! Compártelo
   con tus 10 amigos.
4. (Opcional) En **Site settings → Change site name** puedes ponerle un
   nombre más bonito, por ejemplo `pichanga-septiembre.netlify.app`.
5. (Opcional, si tienes un dominio propio) En **Domain settings** puedes
   conectar tu propio dominio, gratis también.

> Alternativa: si prefieres Vercel, el proceso es igual de simple — creas
> cuenta en vercel.com, subes el mismo proyecto como "sitio estático" (sin
> framework) y te da un link `.vercel.app`.

---

## Cómo funciona

- Al entrar, ves la lista de **eventos** (ej. "Fútbol de septiembre",
  "Salida al cine"). Cualquiera puede tocar **"+ Crear evento"**, ponerle
  nombre, y aparece en la lista para todos.
- Al tocar un evento entras a su calendario propio: cada evento tiene su
  propia disponibilidad, completamente separada de los demás.
- Dentro de un evento, cada persona toca **"+ Añadir disponibilidad"**,
  escribe su nombre y va tocando los días: 1er toque = disponible (verde),
  2do toque = no disponible (rojo), 3er toque = sin marcar.
- Al guardar, la app reemplaza las fechas guardadas de esa persona **para
  ese evento** (si alguien quiere corregir, vuelve a entrar con el mismo
  nombre exacto y remarca).
- El calendario resalta con ⭐ el/los día(s) con más gente disponible, y
  la tarjeta de arriba muestra la mejor fecha con el conteo de amigos
  libres.
- Compartir un evento directo: cuando entras a uno, la URL cambia a algo
  como `tusitio.netlify.app/?event=3` — puedes copiar y mandar ese link
  directo a tus amigos para que abran justo ese evento.
- El switch ☀️/🌙 cambia entre modo claro y oscuro (se guarda en el
  celular de cada persona).

## Notas y límites (a propósito, para mantenerlo simple)

- No hay contraseñas ni cuentas — cualquiera con el link puede escribir.
  Está pensado para un grupo cerrado de confianza.
- Como se identifica a cada persona por el nombre que escribe, pide que
  todos usen el mismo nombre (con apellido) cada vez para evitar
  duplicados como "Luis" y "luis ".
- El plan gratis de Supabase alcanza de sobra para un grupo de 10-30
  personas usando esto ocasionalmente.
